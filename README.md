# My-First-Website-Structure

This is my **first website project**, created while learning the basics of **Git and GitHub** through the CodeWithHarry tutorial.

The main purpose of this project is not only to create a simple website, but also to understand how developers use Git and GitHub to manage, track, and share their code.

## 📌 About the Project

This project contains the basic structure of a website. I created it as a beginner while learning how websites are built using HTML and CSS.

Through this project, I practiced creating files, writing basic website code, organizing a project, and using Git to track changes.

## 🔧 Git Commands Practiced

While working on this project, I practiced several Git commands, including:

```bash
git init
git status
git add .
git commit -m "Initial commit"
git log
git branch
git remote -v
git push
git pull
```

I also learned how to configure Git, including setting my username, email, and default branch:

```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
git config --global init.defaultBranch main
```

## 🔄 Basic Git Workflow

The basic workflow I followed was:

```text
Create / Edit Files
       ↓
   git status
       ↓
    git add
       ↓
   git commit
       ↓
   git push
       ↓
     GitHub
```

This helped me understand how changes made on my computer can be tracked using Git and then uploaded to GitHub.
